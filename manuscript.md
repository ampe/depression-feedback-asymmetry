# Влияние обратной связи на нелинейную динамику ЭЭГ при депрессии: анализ Hurst и экспоненты Ляпунова

## Аннотация
В данной работе мы исследуем отличия нелинейной динамики ЭЭГ у пациентов с большим депрессивным расстройством (MDD) и здоровых участников (Healthy) в условиях обратной связи (feedback) и повторных блоков эксперимента. Для количественной оценки динамики использовались: (i) экспонента Хёрста (Hurst exponent) по методу R/S, (ii) экспонента Ляпунова (MLE, MLE per second) по алгоритму Rosenstein и (iii) прокси энтропии Колмогорова–Синая (KS) как сумма положительных оценок спектра Ляпунова по методу Eckmann et al. Значения вычислялись для сетевого ROI в ЭЭГ (`central_left | base`) и агрегировались на уровне испытуемого (subject-level). Статистический анализ проводился методом смешанной ANOVA с within-фактором `block` (1–3) и between-фактором, учитывающим комбинированные уровни `group`, `condition` и `sex`. 

Ключевые результаты для ROI `central_left | base | fb2` показывают наличие значимых эффектов по `group-condition-sex` и `block` для обеих зависимых переменных (Hurst и MLE), при этом взаимодействие `group-condition-sex × block` не достигает статистической значимости.

## 1. Введение
Нелинейные свойства нейронных сигналов могут отражать устойчивость динамики и скорость дивергенции траекторий во времени. Экспонента Хёрста характеризует персистентность временных рядов (устойчивость к изменениям), а экспонента Ляпунова (MLE) описывает скорость расхождения ближайших траекторий в фазовом пространстве. 

В психиатрических популяциях (включая MDD) динамика нейросистемы может отличаться как по среднему уровню, так и по реактивности на когнитивные/сенсомоторные контексты. В экспериментальной задаче присутствуют события обратной связи (feedback) и повторные блоки измерений. Под `feedback` понимаются события, соответствующие фазе предоставления обратной связи, а под `block` — последовательные сегменты эксперимента, в рамках которых динамика оценивалась отдельно.

## 2. Данные и дизайн исследования
Эксперимент включает два уровня группы (`Healthy`, `MDD`), два уровня feedback/условий (`negative`, `positive`) и три блока повторных измерений (`block` = 1, 2, 3; каждый блок соответствует последовательным ~10 триалам). Анализ выполнялся на ROI `central_left | base` и feedback-коде `fb2` (код события `type=6`). 

Для статистики используется таблица на уровне испытуемого `outputs/subject_level_metrics.csv`, содержащая агрегированные значения `hurst_mean`, `mle_mean` и (после расширения пайплайна) `ks_mean` для каждого сочетания факторов:
`subject_id, group, condition, sex, network, network_variant, feedback, block`.

## 3. Предобработка и извлечение событий
### 3.1. Кодирование событий и определение окон
Из исходных файлов событий (`*_ev.txt`) извлекались дискретные события с полями:
`latency` (в миллисекундах) и `type` (числовой код события).

Внутри каждого сеанса триггеры сегментации строились следующим образом:
1. Опорные события начала триала задавались `START_CODE = 2`.
2. События обратной связи выбирались по кодам:
   - `FB1_CODE = 12`
   - `FB2_CODE = 6`
3. Для каждого события feedback определялся номер триала; номер блока вычислялся как функция номера триала (группировка по 10 триалов на блок).
4. Для каждого события feedback строилось окно анализа длительностью `tmax_sec - tmin_sec` (по умолчанию `tmin_sec=0.0`, `tmax_sec=1.0`), привязанное к моменту feedback-события.

Важно: в рамках разработки пайплайна была выполнена проверка согласованности кодов feedback для всех групп/условий, включая случаи, где файлы Healthy-сессий представлены отдельными форматами (`*_12_ev.txt`). Для публикации используется feedback `fb2`, соответствующий коду `type=6`.

### 3.2. Конвертация событий в выборки
При ветке загрузки EDF события из `latency` (ms) конвертировались в индексы выборок как:
`sample = round(latency_ms * sfreq / 1000)`,
где `sfreq` — частота дискретизации сигнала.

## 4. Метрики нелинейной динамики
### 4.1. Экспонента Хёрста (R/S)
Экспонента Хёрста (`hurst_rs`) оценивалась методом rescaled range (R/S). 
Ключевые свойства:
- значение H лежит в диапазоне (0,1);
- H > 0.5 интерпретируется как персистентность: отклонение сигнала в одном направлении с большей вероятностью сохраняется некоторое время;
- H < 0.5 — антиперсистентность: отклонение сигнала с большей вероятностью “возвращается” и меняет направление;
- H ≈ 0.5 — поведение, близкое к белому шуму: прошлые значения слабо предсказывают будущие.

В расчёте использовались логарифмически распределённые длины сегментов, далее оценивался наклон зависимости `log(R/S)` от `log(n)`.

### 4.2. Экспонента Ляпунова (MLE, Rosenstein)
Экспонента Ляпунова (`rosenstein_mle`) оценивалась по алгоритму Rosenstein:
- строилась фазовая реконструкция с размерностью `embed_dim=6` и лагом `lag=5`;
- далее выполнялся поиск ближайших соседей в фазовом пространстве с исключением по Theiler (`theiler=50`);
- рассчитывалась дивергенционная кривая `d(k)` и оценивался наклон линейного участка;
- значение наклона переводилось в MLE per second.

Если сигнал использовался недостаточный по длине, MLE помечалась как отсутствующая (None/NaN) и исключалась из агрегации.

### 4.3. Прокси энтропии Колмогорова–Синая (KS) и спектр Ляпунова (Eckmann)
В теории динамических систем энтропия Колмогорова–Синая (KS) характеризует скорость генерации новой информации траекторией на аттракторе. При выполнении стандартных условий гладкости (идентичность Песина) KS связана со **спектром показателей Ляпунова** \(\{\lambda_i\}\): в частности, в типичных гиперболических постановках KS совпадает с **суммой положительных** \(\lambda_i\). Для одномерной реконструкции по временному ряду мы оценивали набор экспонент методом **Eckmann et al. (1986)** (реализация `nolds.lyap_e`), который восстанавливает локальную линейную динамику в окрестностях точек реконструированной орбиты и по последовательности якобиановых шагов получает оценки \(\hat{\lambda}_1,\ldots,\hat{\lambda}_d\) (здесь \(d=\) `matrix_dim`).

**Связь и отличие от MLE (Rosenstein).** Алгоритм Rosenstein (раздел 4.2) оценивает **один** показатель, интерпретируемый как **наибольший** (или доминирующий) экспонент Ляпунова для выбранной реконструкции. Метод Eckmann оценивает **несколько** экспонент одновременно и тем самым позволяет построить скаляр, согласованный с идеей KS как **суммы положительных** компонент спектра. При этом **фазовые реконструкции не тождественны**: Rosenstein использует задержку `lag=5` между координатами вложения; в реализации Eckmann через `nolds` используется вложение с **единичным** шагом по выборкам внутри орбиты (параметры `emb_dim` и `matrix_dim` задают размерность спектра и структуру локальных отображений). Поэтому величины MLE и сумма положительных \(\hat{\lambda}_i\) **не дублируют** друг друга: это разные оценки разных объектов (один старший экспонент vs. вектор экспонент при другом вложении).

**Параметры, согласованные с MLE.** Для сопоставимости настроек использовались те же `embed_dim=6` и то же минимальное **временное** разделение соседей, что и для Rosenstein: в индексах исходного ряда задавалось исключение Theiler `theiler=50`. Для длинных конкатенированных сегментов выполнялось **равномерное прореживание** с целым шагом `stride` по времени (не более ~4096 отсчётов после прореживания), чтобы вычисление Eckmann оставалось практичным: при прореживании шаг дискретизации для нормировки экспонент задавался как `stride/sfreq`, а порог Theiler в индексах прореженного ряда масштабировался как \(\lceil \texttt{theiler}/\texttt{stride}\rceil\).

**Итоговый скаляр для анализа.** На уровне одной ячейки `(feedback × block × network × network_variant)` сохранялись: вектор `ks_lexp_0…ks_lexp_5` при `matrix_dim=6` и скаляр **`ks_sum_pos_per_sec`** — сумма положительных оценок \(\max(0,\hat{\lambda}_i)\) (в единицах 1/с после нормировки `nolds`). На уровне испытуемого в `subject_level_metrics.csv` усреднение по соответствующим строкам даёт **`ks_mean`**.

## 5. ROI и агрегация по сетям
Мы использовали сетевые ROI из фиксированных списков каналов:
`BASE8_NETWORKS["central_left"] = ["C3"]`.
Параметр `network_variant="base"` означает использование только базовых (lateral) каналов из соответствующего определения сети (например, для `central_left | base` ROI фактически соответствует только каналу `C3`).
Параметр `network_variant="base_midline"` означает расширение ROI за счёт дополнительных midline-каналов (например, `FCZ`, `CZ`) согласно определению в конфигурации сетей.

В основной анализ входили данные только для `network_variant="base"` и `network="central_left"`. 
Сигнал ROI в каждом окне формировался усреднением по соответствующим каналам.

Для каждой комбинации:
`feedback × block × network × network_variant` 
окна внутри испытуемого конкатенировались, после чего рассчитывались Hurst, MLE (Rosenstein), спектр Eckmann (`ks_lexp_*`) и скаляр `ks_sum_pos_per_sec` (сумма положительных компонент спектра) для данной ячейки.

## 6. Привязка пола (sex) к испытуемым
Пол (sex) извлекался из файла `events F32/ID gender.xlsx`, где:
- `gender=1` соответствует `M`,
- `gender=2` соответствует `F`,
- пустые строки и `0` рассматривались как отсутствие данных.

Критически важным этапом было корректное согласование идентификаторов между таблицей событий и таблицей `subject_info.csv`. В `subject_id` условие (positive/negative) кодируется последней цифрой, поэтому для маппинга sex использовался базовый идентификатор, получаемый от `subject_id` удалением последней цифры-condition (например, `S011/S012` относятся к одному базовому ID).

После заполнения `outputs/subject_info.csv` пол присоединялся к агрегированным метрикам в `scripts/build_subject_level_metrics.py`.

## 7. Статистический анализ
### 7.1. Агрегация
Таблица `outputs/subject_level_metrics.csv` создавалась функцией:
`python scripts/build_subject_level_metrics.py`.

Она объединяла:
- `outputs/lyapunov_long.csv` → среднее `mle_mean` по окна/событиям и среднее `ks_mean` по `ks_sum_pos_per_sec` (если колонка присутствует),
- `outputs/hurst_long.csv` → среднее `hurst_mean`,
и добавляла `sex` из `outputs/subject_info.csv`.

### 7.2. Смешанная ANOVA (mixed ANOVA)
ANOVA выполнялась для ROI:
`central_left | base | fb2` (основной ROI для иллюстраций/детального описания).

Для оценки устойчивости эффекта по различным областям мозга mixed ANOVA дополнительно выполнялась для всех ROI (left/right варианты) при `network_variant="base"` и `feedback="fb2"`:
`central_left`, `central_right`, `frontal_left`, `frontal_right`, `parietal_left`, `parietal_right`, `occipital_left`, `occipital_right`.

Зависимые переменные:
- `hurst_mean`
- `mle_mean`

within-фактор:
- `block` (1, 2, 3)

between-фактор:
- комбинированный фактор `group_cond_sex = group-condition-sex`,
где `condition` = positive/negative.

Перед запуском ANOVA отбирались субъекты, у которых присутствовали все блоки 1..3.

Оценка эффектов проводилась методом pingouin `mixed_anova`.
Первичные результаты (для `central_left | base | fb2`) сохранялись в `outputs/anova_roi_report.txt`,
а сводка по всем ROI — в `outputs/anova_all_rois_report.txt` / `outputs/anova_all_rois_summary.csv`.

## 8. Результаты
### 8.1. Mixed ANOVA: Hurst
Для ROI `central_left | base | fb2` смешанная ANOVA по `hurst_mean` показала:
1. Эффект `group-condition-sex`:
   - **F(7,140)=19.8037**, **p<0.0001**
2. Эффект `block`:
   - **F(2,280)=37.4199**, **p<0.0001**
3. Взаимодействие:
   - **F(14,280)=0.6889**, **p=0.7849**

Для анализа использовано **n=148 subject_id** (это количество строк на уровне “условие-сессия” после фильтра по полным блокам 1..3 и не-пустым значениям), что соответствует доступным данным для mixed ANOVA.

Таким образом, наблюдается **значимый основной эффект `block`** (изменения между блоками 1→3), а также **значимый основной эффект `group-condition-sex`** (различия между подгруппами Healthy/MDD × negative/positive при учёте sex). При этом **взаимодействие `group-condition-sex × block` не значимо**, то есть форма динамики между блоками не отличается между подгруппами.

### 8.2. Mixed ANOVA: MLE
Для ROI `central_left | base | fb2` смешанная ANOVA по `mle_mean` показала:
1. Эффект `group-condition-sex`:
   - **F(7,140)=8.6778**, **p<0.0001**
2. Эффект `block`:
   - **F(2,280)=36.5477**, **p<0.0001**
3. Взаимодействие:
   - **F(14,280)=0.7292**, **p=0.7444**

Аналогично Hurst, **основные эффекты `block` и `group-condition-sex` значимы**, а **взаимодействие `group-condition-sex × block` не значимо**, что указывает на сопоставимый паттерн изменения между блоками при различающихся уровнях между подгруппами.

### 8.5. Sex-only различия внутри group×condition (fb2, central_left | base)
Отдельно для `central_left | base | fb2` была выполнена mixed ANOVA, где:
- within-фактор: `block (1..3)`;
- between-фактор: `sex (M/F)`;
- тестировалось в каждом subset `group × condition`.

**Hurst (`hurst_mean`)**:
- `Healthy-negative`: sex не значим, **F(1,35)=2.14, p=0.153**; взаимодействие не значимо, **F(2,70)=0.11, p=0.898**.
- `Healthy-positive`: sex не значим, **F(1,40)=2.28, p=0.139**; взаимодействие не значимо, **F(2,80)=0.77, p=0.467**.
- `MDD-negative`: sex “на грани”, **F(1,34)=3.52, p=0.069**; взаимодействие не значимо, **F(2,68)=0.10, p=0.908**.
- `MDD-positive`: sex значим, **F(1,31)=9.95, p=0.0036**; взаимодействие не значимо, **F(2,62)=0.13, p=0.874**.

**MLE (`mle_mean`)**:
- во всех subset `group×condition` эффект `sex` не достигал значимости (например `MDD-positive`: **F(1,31)=0.01, p=0.937**), при этом основной эффект `block` был значимым почти во всех subset.

В целом: sex-эффект проявлялся для Hurst преимущественно в `MDD-positive`, а различия между мужчинами и женщинами не сопровождались изменением формы динамики по блокам (взаимодействие `sex × block` всюду незначимо).

### 8.6. Healthy vs MDD внутри condition (fb2, central_left | base)
Для замены пункта про “корреляции” была выполнена mixed ANOVA отдельно для `condition=positive` и `condition=negative`:
- within: `block`;
- between: `group (Healthy/MDD)`;
- DV: `hurst_mean` или `mle_mean` (sex учитывался только через агрегацию/коллапс по subset).

**Hurst (`hurst_mean`)**:
- `negative`: group не значим, **F(1,71)=0.27, p=0.604**; взаимодействие `group×block` не значимо, **F(2,142)=0.57, p=0.568**.
- `positive`: group значим, **F(1,73)=83.23, p<0.0001**; взаимодействие значимо, **F(2,146)=3.43, p=0.035**.

**MLE (`mle_mean`)**:
- `negative`: group не значим (**F(1,71)=3.26, p=0.075**).
- `positive`: group значим, **F(1,73)=36.86, p<0.0001**; взаимодействие не значимо, **F(2,146)=1.47, p=0.233**.

Таким образом, различия между Healthy и MDD выражены преимущественно для `positive`, а по Hurst дополнительно различается и паттерн изменения по блокам (значимое `group×block`).

## 9. Обсуждение
Отсутствие значимого взаимодействия `group-condition-sex × block` у обеих метрик (`hurst_mean` и `mle_mean`) означает, что **форма динамики между блоками (1→3) статистически сопоставима между подгруппами**, тогда как **основные эффекты** по `block` и по `group-condition-sex` сохраняются.

`group-condition-sex` — это комбинированный между-фактор (group × condition × sex). Его значимость означает, что средние значения `hurst_mean`/`mle_mean` различаются между комбинированными подгруппами (Healthy/MDD × positive/negative × sex).

Для более прямой интерпретации различий между **Healthy и MDD** дополнительно была выполнена отдельная mixed ANOVA, где значения усреднялись по `condition` и `sex` (between-фактор: `group`, within-фактор: `block`). В ROI `central_left | base | fb2`:
- для `hurst_mean` эффект `group`: **F(1,87)=36.3946, p<0.0001**, эффект `block`: **F(2,174)=40.0012, p<0.0001**, взаимодействие `group×block`: **F(2,174)=1.5445, p=0.2163**;
- для `mle_mean` эффект `group`: **F(1,87)=5.1410, p=0.0258**, эффект `block`: **F(2,174)=48.8159, p<0.0001**, взаимодействие `group×block`: **F(2,174)=0.6506, p=0.5229**.

Таким образом, различия между Healthy и MDD сохраняются при усреднении по `condition` и `sex`, а характер изменения по блокам остаётся сопоставимым (незначимое взаимодействие).

В контексте задачи `positive/negative` отражают разные состояния, связанные с валентностью обратной связи, а фактор `block` соответствует последовательному изменению динамики во времени (в эксперименте по мере продолжения серии). Знаковые эффекты `block` для обеих метрик указывают на то, что нелинейные свойства сигналов (персистентность по Hurst и скорость дивергенции по MLE) систематически меняются от блока к блоку. Поскольку при этом взаимодействие `group-condition-sex × block` не значимо, характер перестройки динамики по блокам качественно сопоставим между подгруппами, хотя их абсолютные уровни могут отличаться.

Отдельные “sex-only” тесты внутри каждого subset `group×condition` были выполнены для `central_left | base | fb2`. Для `hurst_mean` значимый sex-эффект наблюдался только в `MDD-positive` (при незначимом `sex × block`), тогда как для `mle_mean` sex-эффект в subset не достигал значимости.

Для замены “корреляций Healthy-positive vs MDD-positive” была выполнена mixed ANOVA `Healthy vs MDD` отдельно для `condition=positive/negative`. Значимые `group`-различия выявлены преимущественно для `positive`, а для Hurst дополнительно оказалось значимым взаимодействие `group×block` в `positive`.

## 10. Ограничения
1. Mixed ANOVA требует согласованности данных по within-фактору; анализ ограничивался субъектами с полными блоками 1..3.
2. В графиках sex не визуализируется отдельно, так как ANOVA учитывает sex в статистике комбинированным between-фактором.
3. ROI анализ выполнялся для всех областей в `network_variant="base"` (left/right центральные, фронтальные, париетальные и затылочные). В разделе визуализации показан primary ROI `central_left`, а сводные статистические результаты приведены в таблице по ROI.
4. Идея про “корреляции” между Healthy-positive и MDD-positive была заменена корректным факторным тестом: `Healthy vs MDD` отдельно внутри `positive/negative` (mixed ANOVA).
